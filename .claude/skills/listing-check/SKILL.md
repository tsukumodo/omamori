# リスティングページの検証

`Website/index.html` と `Website/app.js` は Scriban テンプレートで、
package-list-action がビルド時に実データで描画してはじめて完成する。
このスキルは「描画後のページ」を手元で確かめるための手順と、
過去のレビュー12巡で実際に踏んだ穴から作ったチェックリスト。

## プレビュー

```bash
node tools/listing-preview/preview.mjs          # _preview/ に描画
node tools/listing-preview/preview.mjs --serve  # ポート4173で配信
```

- フィクスチャは `tools/listing-preview/fixtures/listing.json`。
  **本番の package.json と同じ形を保つこと**（空の任意項目は空のまま）。
  フィクスチャが本番より豊かだと、本番でだけ起きる不具合（空文字→死んだリンク）が
  永久に見えない。実例が2件ある（ライセンス欄・作者欄）。
- Playwright で描画確認するときは Google Fonts への外部リクエストを
  `route().abort()` で止め、`waitUntil: 'load'` を使う（networkidle は返ってこない）。

## チェックリスト（全項目必須）

### 1. テンプレート契約
- 描画結果に未置換の `{{` が **0件**。
- プレースホルダ（listingInfo.Url / packages ループ / package.* 各項目）の書式を変えない。
- **HTMLコメントの中にテンプレートタグの表記を書かない。** Scriban はコメント内も
  解釈する。過去にコメント内の for タグ表記でページ全体がパッケージ数ぶん
  複製される事故が起きた。

### 2. リンク
- `|| '#'` のようなフォールバックは禁止。任意項目が空のときは **href を外す**
  （href の無い `<a>` はリンク扱いされずフォーカスも受けない）。
- 描画結果に `href="#"`・`href=""`・`github.com` への参照が **0件**。

### 3. はみ出し・折り返し
- **親要素基準と対ビューポートの両方**で測る。`body { overflow-x: hidden }` が
  はみ出しを隠すので、scrollWidth だけ見ても検出できない。
- 検証幅は **280 / 320 / 360 / 390 / 480 / 600 / 768 / 900 / 1280 / 1920px**。
  480px を抜くと孤児行を見逃す（実績あり）。
- `white-space: nowrap` を足すときは親基準で 280px まで安全確認。
- 孤児行（最終行が極端に短い）と、文節・て形の途中の割れも見る。

### 4. 表示切替（hidden / display）
- `hidden` 属性の有無ではなく、**getBoundingClientRect().height と offsetParent で
  描画を確認し、見えている要素の数を数える**。作者オリジンの `display: flex` は
  UA の `[hidden] { display: none }` に勝つため、属性が付いても消えない罠がある
  （検索フィルタがこれで3巡「確認済み」をすり抜けた）。

### 5. 色・コントラスト
- ライト / ダーク両方で測る。数値には**式と分母**を併記し、**描画画素**で裏を取る。
- 文字 4.5:1（AA）、UI部品・枠線 3:1 を下回らない。
- `box-shadow` 内の `var()` が `none` に展開されると**宣言ごと破棄**される。
  「影なし」を差し込むときは `0 0 #0000` を使う。

### 6. レイアウトの床
- 主CTA が第1画面に入る（1366×768 と 360×640）。
- タップターゲット 44×44px 以上。
- prefers-reduced-motion でアニメーション・目線追従が止まる。

### 7. 検証の姿勢
- **主張は、それを否定しうる方法で検証する。**「◯◯を確認済み」には測定方法を添える。
- 触ったハンクの**副作用まで測り直す**（別セクションの余白・全長・揃え）。
- 不利な事実・判断に迷った点を隠さず報告する。
