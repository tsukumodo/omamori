# つくも堂のデザイン言語

## ページの前提（最重要）

このページへの動線は **BOOTH → 同梱PDF → このページ → VCCで追加** の一本道。
通りすがりに商品を売る店先ではなく、**すでに入手した人を確実に導入まで運ぶ最後の1ページ**。

ここから導かれる規則:
- **他の商品を載せない。** ページはその商品ひとつのためにある。
- **主CTAは VCC**（`vcc://vpm/addRepo?url=...`）。逃げ道はURL手動登録のみ。
- **GitHubへのリンクを出さない**（リポジトリは非公開の扱い）。
- ALCOM は**名前を出すだけ**。外部リンクは張らない。
- 不具合の報告先は **X の DM**。
- zip直リンクは出さない（VPMの更新が届かなくなる4つ目の出口になる）。

## 配色体系: 店＝紺＋金茶 / 商品＝抹茶

| 役割 | トークン | 値 |
|---|---|---|
| 店の紺(地・ヒーロー) | `--omamori-navy` | `#162244` |
| 店の金茶(装飾・紋) | `--omamori-gold` | `#C8A87C` |
| 主CTAの金茶(濃) | `--omamori-gold-deep` | `#AD8B57` |
| 商品の抹茶 | `--omamori-green` | `#467A56` |

- **緑（抹茶）は商品の色。おまもりの絵の中だけに使い、UI部品には使わない。**
  「授かる」は店の側の行為なので CTA は金茶。
- 金茶 `#C8A87C` は白地で 2.25:1 しか出ない。**ボタン等の面には `#AD8B57` を使う。**
- トークンはライト先勝ちで定義し、ダークは上書き。新色を足す前に既存トークンで
  組めないか検討する（レビューで「新色ゼロ」の解が繰り返し勝っている）。

## 組版（和文）

- `word-break: auto-phrase` は見出し・リード・手順など**短文に**。
- `line-break: strict` で行頭禁則（小書き仮名を行頭に落とさない）。
- 手順リスト・カード説明には `text-wrap: balance`。
- `no-orphan` 用の span は**文節・て形を割らない位置**で括る
  （「無効にし/ている」のような割れは孤児行より悪い）。
- 非対応ブラウザでは通常の改行に劣化するだけの書き方に留める。

## 文章のトーン

- です・ます調。道具屋の口上（「授かる」「お渡しする」「守り札」）。
- 深刻度の表示語は**「エラー」「警告」のまま**。和風に言い換えると
  実際の Unity 画面と食い違い、初心者が対応付けられなくなる。
- 絵文字は 🍀 と 🏮 のみ。**「。」の直後に絵文字を置かない**。
  絵文字を構文単位（動詞と補足の間など）に割り込ませない。
- 実装・一次情報で確認していないことを書かない。CHANGELOG は
  「そのバージョン時点の記録」であって現在の実装の説明ではない。

## アクセシビリティの床（下回ったら差し戻し）

- 文字 4.5:1（AA）、UI部品・枠線 3:1。ライト / ダーク両方。
- タップターゲット 44×44px 以上。
- フォーカスリングは**各セクションの背景色に対して**可視であること
  （紺地の上では別トークンに上書きする）。
- prefers-reduced-motion で装飾アニメーションを全停止。
- 状態変化（コピー成功・検索0件）は `role="status"` でも伝える。
